# SaintSolutions

React + Vite + Tailwind CSS + Framer Motion.

    npm install
    npm run dev      # local dev
    npm run build    # production build in /dist

Edit copy, services, projects and pricing in `src/data/content.js`.
Forms log to the console: connect them in `src/components/Form.jsx` (Formspree, EmailJS or your own API).
Replace the placeholder email and location in `Footer.jsx` and `Contact.jsx`.
